Terracotta Themes adds thirteen themes to Paseo. Twelve are fixed: six dark (Charcoal Night, Cocoa Night, Blueberry Night, Harbor Night, Velvet Night and Lagoon Night) and six light (Oat Latte, Sakura Latte, Matcha Latte, Glacier Latte, Orchid Latte and Lagoon Latte). The thirteenth, 🎨 Custom, is a live slot you tune yourself. They appear under Settings → Appearance in every Paseo client connected to a host that has the plugin, on desktop, web and mobile.

All palettes come from one lightness ladder in the OKLCH color space, measured from the color theme built into the Claude Code CLI, with automatic WCAG contrast fitting across all hues. Charcoal Night follows that dark palette with its terracotta accent, lifting two text colors for contrast on Paseo surfaces, and the other eleven reuse the same steps at warm and vivid cool hues, so text contrast and surface depth stay consistent across the family. This is an unofficial project, not affiliated with or endorsed by Anthropic.

The custom theme has its own settings screen (Settings → Plugins → Terracotta Themes → Custom theme, or "Customize the theme" in the command center). Choose dark or light, a hue and tint for the surfaces, and a hue and vividness for the accent, with sliders or step buttons that work on phones. The plugin computes the eight theme colors with the same recipe as the fixed themes, and once 🎨 Custom is selected under Appearance, the whole app takes the new colors each time you let go of a slider. Next to the controls are a small preview window, the eight swatches with their hex values, and the same 25 contrast checks the fixed themes are tested against, each marked pass or fail. Shuffle picks a fresh vivid combination and Reset returns to the default, deep teal with a hot pink accent.

The parameters are a host setting, so every device connected to that host shows the same custom theme. A change saved on one device reaches the others through Paseo's settings events, without polling. The settings screens load the first time you open them.

The screens are in English and Simplified Chinese and follow the device language by default. The plugin's Language settings can pin a language, and you can add your own as JSON files in the plugin's data folder; anything you leave out shows in English. The custom theme's name follows the language; the fixed theme names stay as they are.

The plugin makes no network requests and starts no processes. Its server part stores the custom theme and language settings through Paseo, computes the custom theme's colors so devices only download ready colors, keeps translation templates and your language files in its own data folder, and sends the settings screens' code when they first open. Code blocks keep the syntax highlighting chosen in Appearance. Requires Paseo 0.11.0 or later.
