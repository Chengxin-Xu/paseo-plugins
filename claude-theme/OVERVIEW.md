Terracotta Themes adds twelve color themes to Paseo: six dark (Charcoal Night, Cocoa Night, Blueberry Night, Harbor Night, Velvet Night and Lagoon Night) and six light (Oat Latte, Sakura Latte, Matcha Latte, Glacier Latte, Orchid Latte and Lagoon Latte). They appear under Settings → Appearance in every Paseo client connected to a host that has the plugin, on desktop, web and mobile. All twelve palettes come from one lightness ladder in the OKLCH color space, measured from the color theme built into the Claude Code CLI, with automatic WCAG contrast fitting across all hues. Charcoal Night follows that dark palette with its terracotta accent, lifting two text colors for contrast on Paseo surfaces, and the other eleven reuse the same steps at warm and vivid cool hues, so text contrast and surface depth stay consistent across the family. This is an unofficial project, not affiliated with or endorsed by Anthropic. The plugin contains theme data only: no settings, no server component, no network requests, no file access and no subprocesses. Code blocks keep the syntax highlighting chosen in Appearance. Requires Paseo 0.11.0 or later.
