「拾页 · 项目手记」在 daemon 所在的主机上，为每个 Paseo 项目保存任务、提示词和想法。任务依次经过待办、进行中和已完成；提示词支持可复用的变量；没有归入项目的手记放进「随手记」。要从一条手记「开始处理」，先选择项目和 Agent，再编辑初始任务。另外还有一键发送的提示词胶囊，任务卡上也会显示 Agent 的实时状态。

可以从侧栏、工作区面板或命令中心打开「拾页 · 项目手记」。`/notes` 打开面板，`/notes <text>` 把一条想法记到「随手记」，`/prompt` 打开提示词库。

## 准备工作

需要 Paseo 0.11.1 或更新版本，daemon 和 App 都要满足。不需要账号或 token。从 Git 安装时，准备步骤会按锁文件从 npm 下载 esbuild 和 zod 依赖并构建 CLI，因此主机需要有 npm，并能访问 npm 仓库。「开始处理」需要已配置的 provider；可选的模型和 profile 来自 Paseo。

## 语言

内置英文和简体中文。除非在「设置 → 插件 → 拾页 · 项目手记 → 语言」里指定了语言，否则使用设备语言；CLI 跟随同一选择，缺少翻译时以英文代替。在 `~/.paseo/plugin-data/project-notes/locales/` 里把内置模板复制一份并翻译，就能添加一种语言。手记保留写下时所用的语言。

## 使用手记和提示词

- 手记可以置顶、标为重点、搜索，也可以按项目筛选。并发编辑时，过时的修改会被拒绝，草稿会保留。
- 删除会把手记移到回收站。「彻底删除」需要确认，修改快照也会一并删除。「清空回收站」作用于所选项目范围内回收站里的每一条手记，包括搜索未显示的手记。
- 可见的看板每 5 秒同步一次，一分钟没有变化后改为每 15 秒一次；不可见的看板不轮询。
- 提示词模板里的 `{{variables}}` 按字面替换。在网页和 Mac 桌面端，输入框上方的「提示词」胶囊可以填入输入框、追加到草稿末尾或替换草稿，在继续编辑之前还可以撤销这次填入。在原生 App 上，或无法填入时，仍可使用「复制到剪贴板」。
- 四段模板帮你写明目标、范围、约束和验收。生成建议时会读取项目配置文件（读取量有上限），不执行命令。
- 发送时会检查 Agent（包括未载入的会话），要中断回合或有待审批时先请你确认。「等这一轮结束再发」会把提示词排进插件服务端的队列，由服务端在这一轮结束、没有待审批时发出，App 关着也照样发送。提示词会先写进插件的发送账本；发出之后保留 160 个字符的预览，为期一周。如果排队期间有别人给这个 Agent 发过消息，排队的提示词会停下来等你确认；同一条提示词无论从哪台设备发，都不会同时有两份在路上。在 Paseo 0.11.1 上，使用插件的斜杠命令前请先移除输入框里的附件。

## 一键发送

在提示词详情里打开「一键发送」，这条提示词就会以短胶囊的形式显示在每个 Agent 的输入框上方；超过 3 条时收进一个菜单胶囊。Agent 空闲、未载入或能插话时，点按即发。如果 Agent 正在运行又不能插话，或在等审批，胶囊会先问你：等这一轮结束或审批处理完再发，还是现在仍然发送。仅凭一次点按，绝不会打断回合。含变量的提示词会打开填写表单。一键发送与选择器共用同一个发送账本。这份有序列表是所有设备共用的宿主设置；胶囊跟随它的变更事件更新，不轮询。

## 任务卡状态

任务卡上显示从这条任务启动的 Agent：运行中（蓝色）、等你处理（琥珀色）、完成未读（绿色）、出错（红色）或空闲，并显示子 Agent 和最近活动。点按即可打开该 Agent，详情里列出每一次启动。已归档或已删除的 Agent 显示为「已结束」。状态只来自 Paseo 的 Agent 目录和插件的启动记录；不读取任何会话，所以未载入的 Agent 仍保持未载入。

## 开始处理

选好项目目录或新的 Git worktree、工作区标题、provider、模型和 Agent 设置。确认之前不会创建任何东西。编辑后的初始任务会发送给所选的 provider。随附的来源附件只包含手记编号、标题、项目、状态和重点，不会重复已保存的正文。输入框的附件选择器是单独的功能，明确选中手记时仍会附上手记内容。

工作区沿用你填写的标题，worktree 使用 `notes/<id>`；不会发起自动命名调用。重复的请求会复用创建幂等键。中断之后，找回流程按 Agent 标签和 worktree 标识查找已有资源，而不是新建；只有确认在创建之前就被拒绝，才允许换新的选项重新开始。结果无法确定时，需要到 Paseo 里核对。

## 数据与命令行

手记以未加密的 JSON 保存在 `$PASEO_HOME/plugin-data/project-notes/boards/` 下，快照单独存放在 `boards/history/`，启动阶段存放在 `launches/`。默认的 Paseo 主目录是 `~/.paseo`。启动记录包含资源 ID、手记编号、启动输入的哈希值，以及 provider 或 daemon 报告的错误（最多 500 个字符），不包含任务文本。一键发送列表存放在 `plugin-settings/project-notes/quick-prompts.json`，内含手记编号、项目和标题副本。插件和 CLI 的更新由原子写入和两者共用的锁保护。语言状态和翻译模板也存放在这些文件旁边。卸载插件后，数据仍留在原处。

修改标题、正文或类型时会保留最近 10 个快照；修改状态不会。旧版内嵌在看板里的历史会无损迁移。看板按版本 2 写入，所以**升级后不能直接回滚到 0.9.0**。请把整个数据目录一起备份、一起恢复；缺失的快照会提示出来，确认后可以在手记详情里放弃对它们的引用。

`node bin/notes.mjs --help` 列出 CLI 命令。即使是 `list` 和 `show`，也可能迁移旧数据，并写入看板、历史和锁文件。正文文件输入接受不超过 96000 字节的普通文件，或有上限的标准输入。主机上的其他账号能看到命令行，所以私密文字要用 `--body-file -` 传入，绝不要用 `--body`，也不要写进标题。

## 限制与隐私

每个项目最多 4000 条手记（含回收站），看板最大 32 MiB；总览最多载入合计 32 MiB 的看板。超出上限的看板会显示为不可用。手记留在各自的 daemon 上，所有使用这个 daemon 的人都能访问；不要存放密码和密钥。插件本身不发起网络请求。「开始处理」会把确认后的任务和来源元数据经 Paseo 发送给所选的 provider。
