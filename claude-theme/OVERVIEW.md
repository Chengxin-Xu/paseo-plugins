Terracotta Themes adds six color themes to Paseo: three dark (Charcoal Night, Cocoa Night and Blueberry Night) and three light (Oat Latte, Sakura Latte and Matcha Latte). They appear under Settings → Appearance in every Paseo client connected to a host that has the plugin, on desktop, web and mobile. All six palettes come from one lightness ladder in the OKLCH color space, measured from the color theme built into the Claude Code CLI. Charcoal Night reproduces that dark palette with its terracotta accent, and the other five reuse the same steps at different hues, so text contrast and surface depth stay consistent across the family. This is an unofficial project, not affiliated with or endorsed by Anthropic. The plugin contains theme data only: no settings, no server component, no network requests, no file access and no subprocesses. Code blocks keep the syntax highlighting chosen in Appearance. Requires Paseo 0.11.0 or later.
