Terracotta 主题为 Paseo 新增十三套主题。其中十二套是固定主题：六套深色（Charcoal Night、Cocoa Night、Blueberry Night、Harbor Night、Velvet Night 和 Lagoon Night），六套浅色（Oat Latte、Sakura Latte、Matcha Latte、Glacier Latte、Orchid Latte 和 Lagoon Latte）。第十三套「🎨 自定义」是一个由你自己调色的实时主题槽。这些主题出现在「设置 → 外观」里；只要 Paseo 客户端连接的主机装了本插件，桌面端、网页端和手机端都能看到。

所有配色都出自 OKLCH 色彩空间里的同一条明度阶梯，这条阶梯是从 Claude Code CLI 内置的配色主题测出来的；每个色相上的对比度都按 WCAG 自动拟合。Charcoal Night 沿用这套深色配色和它的赤陶强调色，提亮了其中两种文字颜色，以保证它们在 Paseo 表面上的对比度；其余十一套在暖色和鲜艳冷色的色相上复用同样的几级明度，所以整个家族的文字对比度和表面层次都保持一致。这是一个非官方项目，与 Anthropic 没有关联，也未获 Anthropic 认可。

自定义主题有自己的设置页（「设置 → 插件 → Terracotta 主题 → 自定义主题」，或命令中心里的「调整自定义主题」）。可以选深色或浅色，选底色的色相和浓度、强调色的色相和鲜艳度，用滑杆或在手机上也好用的步进按钮调节。插件用与固定主题相同的配方算出主题的八个颜色；在「外观」里选中「🎨 自定义」后，每次松开滑杆，整个界面都会换上新颜色。控件旁边有一个小预览窗、带 hex 值的八个色块，以及固定主题测试所用的同一组 25 项对比度检查，每项都标明达标或未达标。「随机一组」挑一组新的鲜艳搭配，「恢复默认」回到默认配色：深青底配亮粉强调色。

这些参数是主机设置，所以连到这台主机的每台设备显示的都是同一套自定义主题。在一台设备上保存的修改，会通过 Paseo 的设置变更事件传到其他设备，无需轮询。设置页在你第一次打开时才加载。

这些设置页提供英文和简体中文，默认跟随设备语言。插件的「语言」设置可以固定一种语言，你也可以把自己的语言写成 JSON 文件，放进插件的数据文件夹；你没翻译的条目都显示英文。自定义主题的名字跟着语言走；固定主题的名字保持原样。

插件不发起网络请求，也不启动进程。它的服务端部分通过 Paseo 保存自定义主题和语言设置；计算自定义主题的颜色，让设备只下载算好的颜色；在自己的数据文件夹里存放翻译模板和你的语言文件；并在设置页第一次打开时发送它们的代码。代码块沿用在「外观」里选的语法高亮。需要 Paseo 0.11.0 或更高版本。
